# Atharv Jamdade — Portfolio (React + Vite)

## Run
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in /dist
```

## Edit
- Text/content: `src/components/*.jsx`
- Colors & fonts: top of `src/styles.css` (`:root` variables)
- Project links: `PROJECTS` array in `src/components/Work.jsx`
- LinkedIn URL: `src/components/Contact.jsx`
